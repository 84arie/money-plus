Money+ PWA
==========
Upload ALL files/folders in this package to a HTTPS web host (for example GitHub Pages).
Required:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/

After hosting, open the HTTPS URL on the phone and choose Add to Home Screen / Install App.
Data currently remains in browser/app local storage on that device. Use Money+ Backup Data regularly.
